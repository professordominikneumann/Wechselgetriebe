# Wechselgetriebe – interaktive 3D-Modelle

Einstieg: `index.html` (gleichachsiges und ungleichachsiges Wechselgetriebe, Einführung, Synchronisierung, Arbeitsblätter, Übungsaufgaben, Quiz und Lernspiel).

- `einfuehrung.html` – animierte Schritt-für-Schritt-Einführung: Bauart erkennen, Zahnräder Z1–Z13 benennen, Kraftfluss bestimmen
- `synchronisierung.html` – Lerneinheit zur Borg-Warner-Sperrsynchronisierung mit Evolventenverzahnung, Sperrprinzip, Explosionsansicht und Bildern aus dem 3D-Modell
- `arbeitsblatt_gleichachsig.pdf`, `arbeitsblatt_ungleichachsig.pdf` – Arbeitsblätter (DIN A4, je 4 Seiten): Bauteile benennen, Bauart erkennen, Zahnräder zuordnen, geschalteten Gang bestimmen
