# Wechselgetriebe – interaktive 3D-Modelle

Einstieg: `index.html` (gleichachsiges und ungleichachsiges Wechselgetriebe, Einführung, Synchronisierung, Übungsaufgaben, Quiz und Lernspiel).

- `einfuehrung.html` – animierte Schritt-für-Schritt-Einführung: Bauart erkennen, Zahnräder Z1–Z13 benennen, Kraftfluss bestimmen
- `synchronisierung.html` – Lerneinheit zur Borg-Warner-Sperrsynchronisierung mit Evolventenverzahnung, Sperrprinzip und Bildern aus dem 3D-Modell
